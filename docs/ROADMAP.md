# نقشه راه توسعه — MVP در برابر نسخه کامل

بر اساس درخواست شما، دامنه پروژه به **هسته اولیه (MVP)** و **لایه‌های توسعه** تفکیک شده است.
دلیل: ساخت هم‌زمان تمام ۱۵۰ قابلیت از روز اول، ریسک پروژه را به‌شدت بالا می‌برد.

## 🟡 لایه دوم — توسعه‌های آماده‌شده در معماری (پیاده‌سازی نشده)

این موارد **عمداً** پیاده‌سازی نشده‌اند تا پروژه بیش از حد بزرگ نشود، اما معماری برایشان آماده است:

| قابلیت | چه چیزی آماده است | کار باقی‌مانده |
|--------|-------------------|----------------|
| **پیامک (SMS)** | `NotificationChannelAdapter` interface + صف `notifications` | نوشتن `KavenegarAdapter` (~۸۰ خط) |
| **ایمیل** | همان interface | نوشتن `SmtpAdapter` |
| **OPAC / کاتالوگ عمومی** | ماژول `catalog` مستقل + `PublicBookDto` بدون فیلد حساس | یک Controller عمومی + صفحات جستجوی عمومی |
| **پنل اعضا و رزرو آنلاین** | `Member` + `Reservation` کامل | احراز هویت اعضا (جدا از `User`) + UI |
| **اپ موبایل** | REST API کامل + Bearer Token | اپ React Native / Flutter |
| **چند شعبه (Multi-Branch)** | `branchId` روی همه موجودیت‌ها + جدول `Transfer` | UI انتخاب شعبه و گردش انتقال |
| **جستجوی معنایی** | `SearchProvider` interface | افزودن `pgvector` + `VectorSearchProvider` |
| **هوش مصنوعی** | `AiService` contract تعریف‌شده | پیاده‌سازی خلاصه‌سازی / پیشنهاد دسته‌بندی |
| **دریافت خودکار اطلاعات از ISBN** | `IsbnLookupProvider` interface + `NullProvider` فعال | افزودن Provider (Google Books / خانه کتاب) |
| **PWA / آفلاین** | `vite-plugin-pwa` پیکربندی‌شده | استراتژی Offline Queue |

**اصل حاکم:** هیچ دکمه یا صفحه‌ای که کار نکند در UI وجود ندارد. موارد بالا در UI نمایش داده نمی‌شوند تا زمانی که پیاده‌سازی شوند (طبق قوانین ۱۳۴ و ۱۳۵).

## فازهای اجرا

| فاز | محتوا |
|-----|-------|
| **Phase 0** | معماری، ERD، ساختار پوشه، پکیج مشترک، ابزار فارسی |
| **Phase 1** | Schema + Migration + توابع جستجوی فارسی + Seed مجوزها |
| **Phase 2** | هسته API: احراز هویت، RBAC، Audit، تنظیمات، خطاها، Health، Setup |
| **Phase 3** | کاتالوگ، موجودی فیزیکی، مکان‌ها، اعضا |
| **Phase 4** | امانت، بازگشت، تمدید، رزرو، جریمه، مفقودی |
| **Phase 5** | جستجو، گزارش، داشبورد، Inventory، Import/Export، برچسب، Backup |
| **Phase 6** | Frontend کامل با Design System |
| **Phase 7** | تست، Seed، Perf Seed، Docker، مستندات، QA نهایی |
